# Chewing Gum Bubble Animation

An interactive 3D bubble animation simulating a chewing gum bubble using Three.js, GSAP, and Perlin noise.

## Features

- **Mouse Interaction**: Move your mouse to rotate the bubble in 3D space
- **Click Animation**: Click and hold to compress the bubble, release to see it bounce back elastically
- **Organic Deformation**: Perlin noise creates realistic, wavy surface movements
- **Realistic Lighting**: Multiple directional lights with shadows for depth and atmosphere
- **Responsive Design**: Adapts to different screen sizes

## Demo

Experience the live demo: [Chewing Gum Bubble](https://binaryvortex.github.io/Chewing-Gum/)

## Technologies Used

- **Three.js**: For 3D rendering and scene management
- **GSAP (GreenSock Animation Platform)**: For smooth animations and interactions
- **Perlin Noise**: For generating organic deformations
- **HTML5 Canvas**: For rendering the 3D scene
- **CSS**: For basic styling

## How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/BinaryVortex/Chewing-Gum.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Chewing-Gum
   ```

3. Open `index.html` in your web browser.

No build process or dependencies required - it's a static web page!
